## Featured Projects

### RouteSense-AI: Connected Mobility Intelligence for a Smarter Chennai

Built as **Team Innovex** for the Urban Mobility Challenge, a 24-hour hackathon. The platform analyses Chennai Metro, MTC bus, suburban rail, road-network and bus-stop datasets to identify **multimodal transfer hubs and connectivity gaps**.

- **Technologies:** React, Vite, Tailwind CSS, FastAPI, MySQL, Pandas, NumPy, Scikit-learn, Leaflet
- **Data:** Real datasets provided by a government organization

### AI Payment Scam Detector

Built at **Hack Summit 7.0**. The application reviews a payment and returns a clear decision: **Allow, Verify or Block**.

- **Technologies:** Firebase (authentication and database)
